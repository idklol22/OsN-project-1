# Mini Project 1 - C-Shell

Custom POSIX-compliant C-Shell implementation for Mini Project 1.

## Structure
- `c-shell/`: Source files, headers, and Makefile for C-Shell.
  - `src/`: Implementation files (`main.c`, `lexer.c`, `parser.c`, `exec.c`, `hop.c`, `reveal.c`, `peek.c`, `locate.c`).
  - `include/`: Header files.
  - `Makefile`: Build instructions.

## Build and Run
```bash
cd c-shell
make all
./shell.out
```
